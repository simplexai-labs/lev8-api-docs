---
title: "Create task"
description: "Create an asynchronous Entity Search task."
openapi: "POST /v1/entity-search/create_task"
---

Creates an Entity Search task and returns a `leads_search_id` for later `status` and `fetch` calls.

## Example

```bash
curl "https://app.lev8.com/v1/entity-search/create_task" \
  --request POST \
  --header "Content-Type: application/json" \
  --header "x-api-key: $LEV8_API_KEY" \
  --data '{
    "entity_type": "company",
    "objective": "AI startups that raised Series A in 2024",
    "limit": 20,
    "enrich_fields": ["funding stage", "headcount"]
  }'
```

## Response

```json
{
  "object": "entity_search_task",
  "leads_search_id": "leads_search_01JABCDEF123456789",
  "entity_type": "company",
  "objective": "AI startups that raised Series A in 2024",
  "limit": 20,
  "status": "created",
  "created_at": "2026-08-04T00:00:00Z"
}
```

See [Entity Search](/api-reference/entity-search) for entity types, deduplication, enrichment, and web search guidance.
