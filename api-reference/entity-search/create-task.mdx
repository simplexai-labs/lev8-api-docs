---
title: "Create task"
description: "Create an asynchronous Entity Search task."
api: "POST /v1/entity-search/create_task"
---

Creates an Entity Search task and returns a `leads_search_id` for later `status` and `fetch` calls.

## Headers

| Header | Required | Description |
| --- | --- | --- |
| `Content-Type: application/json` | Yes | Request body must be JSON. |
| `x-api-key` | Yes | Your active lev8 External API key. |
| `Idempotency-Key` | Recommended | A unique value up to 128 characters for one logical task creation request. |

## Request body

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `entity_type` | string enum | Yes | - | `person`, `company`, `twitter_creator`, `youtube_creator`, `tiktok_creator`, `instagram_creator`, or `shopify_store`. |
| `objective` | string | Yes | - | Natural-language search target. |
| `limit` | integer | No | `20` | Maximum number of deduplicated entities to produce. Recommended range is `5` to `500`. |
| `enable_web_search` | boolean | No | `false` | Adds open web search mode on top of database search. Usually increases latency and cost. |
| `enrich_fields` | string[] | No | `null` | Extra fields to return under `entities[].enrich_fields`. |
| `dedup_lev8_leads` | string[] | No | `[]` | Previous `leads_search_id` values whose results should be excluded. |
| `dedup_custom_leads` | string[] | No | `[]` | Existing lead names to exclude from this task. |

## Example

```bash
curl "https://app.lev8.com/v1/entity-search/create_task" \
  --request POST \
  --header "Content-Type: application/json" \
  --header "x-api-key: $LEV8_API_KEY" \
  --data '{
    "entity_type": "company",
    "objective": "AI startups that raised Series A in 2024",
    "limit": 20,
    "enrich_fields": ["funding stage", "headcount"]
  }'
```

## Response

```json
{
  "object": "entity_search_task",
  "leads_search_id": "leads_search_01JABCDEF123456789",
  "entity_type": "company",
  "objective": "AI startups that raised Series A in 2024",
  "limit": 20,
  "status": "created",
  "created_at": "2026-08-04T00:00:00Z"
}
```

See [Entity Search](/api-reference/entity-search) for entity types, deduplication, enrichment, and web search guidance.
