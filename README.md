# lev8 API documentation

Public Mintlify documentation for the lev8 API, including asynchronous Entity Search, Contact Search, API-key credit balance, and the hosted Streamable HTTP MCP endpoint.

## Local preview

Use Node.js 20.17 or later and an LTS release supported by Mintlify. This repository currently uses Node.js 22 for local verification.

```bash
fnm exec --using=22 mint dev --no-open
```

The source contract is maintained in `simplexai/anotherme-api`. Public documentation must describe only behavior that is enabled and supported for external callers; do not publish internal upstream addresses, secrets, draft prices, or unimplemented endpoints.
