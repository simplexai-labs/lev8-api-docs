The Lev8 API turns natural-language objectives into matching entities, contact details, researched answers, enriched records, or extracted public lists. Use the HTTP API from server-side products, or connect an AI client through the hosted MCP endpoint.

## Start with Entity Search

You need an API Token to make requests. [Create one from API Tokens](https://app.lev8.com/api-tokens) and set it in your environment — see [Authentication](/authentication) for a step-by-step guide.

```bash
curl "https://app.lev8.com/v1/entity-search/create_task" \
  --request POST \
  --header "Content-Type: application/json" \
  --header "Authorization: Bearer $LEV8_API_KEY" \
  --data '{
    "entity_type": "company",
    "objective": "AI infrastructure startups in the United States founded since 2023",
    "limit": 20
  }'
```

The response includes a `leads_search_id`. Use it with `GET /v1/entity-search/status` to check progress and `GET /v1/entity-search/fetch` to read available results.

## How it works

| Capability | Endpoint | Model |
| --- | --- | --- |
| Entity Search | `POST /v1/entity-search/create_task` | Asynchronous. Create a task, poll status, fetch results by position. |
| Contact Search | `POST /v1/contact-search` | Synchronous. Returns one email or phone lookup. Charged only on a non-empty result. |
| Deep Search | `POST /v1/deep-search` | Synchronous. Returns a dynamic, non-null JSON answer to a research question. |
| Enrich | `POST /v1/enrich` | Synchronous. Generates an object from entity context and a caller-provided JSON Schema. |
| Extract | `POST /v1/extract` | Synchronous. Returns social, GitHub, or public web-page list data. |
| Credit balance | `GET /v1/credit/balance` | Returns available credits, excluding in-progress reservations. |

Authentication uses an `Authorization: Bearer` header. Entity Search reserves credits up front and settles against `ready_count` when the task completes. Idempotent replays return existing results without duplicate billing. The hosted [MCP endpoint](/mcp-reference) calls the same API and does not bypass scopes, concurrency, or billing.
